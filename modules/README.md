# modules

One module per question. The order is not arbitrary: it follows the gaps that actually block
me, largest first.

1. **Physical risk and geospatial hazard mapping** — the gap I named myself. All my ECB work is
   transition risk, and every bank running a climate ICAAP asks for the physical half.
2. **Investor rather than supervisor view** — financial materiality, transition plans as an
   input to a portfolio decision.
3. **End-to-end carbon accounting** — PCAF financed emissions, product footprint, CBAM.
4. **Production data engineering** — optimised SQL, orchestration, tests, data versioning.
5. **Energy statistics and data quality on national balances.**
6. **Nature and biodiversity, quantified, past framework level.**
7. **Climate into credit metrics** — PD and LGD under NGFS scenarios.
